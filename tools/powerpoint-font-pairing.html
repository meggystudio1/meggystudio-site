PowerPoint font pairing

Heading and body font pairs that are already on Windows and Microsoft Office, so your deck looks the same on every computer. Type your own text to preview them.

The preview uses the fonts installed on this device. If a card looks like plain Arial, that font is not on your computer, but it usually is on a Windows PC with Microsoft Office.

Why stick to fonts that are already installed

A downloaded font looks great on your laptop and breaks on the client's. PowerPoint quietly swaps a missing font for another one, line breaks move, and text spills out of boxes. Every pair here uses fonts that ship with Windows or Microsoft Office, so the deck looks the same on the computer in the meeting room. The tag on each card says where the fonts come from. Pairs tagged Windows, Mac work on both.

Sizes that work on a projector

  • Slide titles: 32 to 44 pt
  • Big numbers and quotes: 54 pt and up
  • Body text: 18 to 24 pt, never below 14 pt
  • Labels and captions: 12 to 14 pt

Use one heading font and one body font. A third font is almost always a mistake. Read our guide to the best fonts for PowerPoint for more examples.

Set the pair once in PowerPoint

  1. Open the Design tab, then Variants, then Fonts, then Customize Fonts.
  2. Set Heading font and Body font to your pair and save it with a name.
  3. Placeholders and new text boxes now use the pair everywhere, and you can switch the whole deck in one click later.

FAQ

What is the best font pair for PowerPoint?

For most business decks, Segoe UI Semibold with Segoe UI, or Calibri with Calibri Light. They are installed on almost every Windows computer and stay readable at small sizes.

Can I use Google Fonts in PowerPoint?

Yes, if you install them, but anyone who opens the file without the font will see a replacement. Embed fonts on Windows (File, Options, Save, Embed fonts) or stick to installed fonts.

Do these fonts work on a Mac?

Pairs tagged Windows, Mac work on both. Office for Mac installs many of the Office fonts too, but Segoe UI and Bahnschrift are Windows only.
