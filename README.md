# MEGGYSTUDIO website

Static site for MEGGYSTUDIO pitch deck templates. No build step.

- `index.html` holds the page, styles and script. Edit the `EDIT HERE` block in the script to change marketplaces, templates, the contact endpoint and the free sample file.
- `assets/slides/` template previews (`h-` hero, `t-` thumbnails, full size otherwise)
- `assets/free/` the free 5-slide sample and its previews
- `assets/story/` Unsplash photos, credited in the FAQ
