FAQ

Do I need to install any fonts?

No. Newspaper Headline uses fonts that come with Microsoft Office, so the layout looks the same on any PC.

Which PowerPoint version do I need?

Morph transitions play in PowerPoint 2019, 2021 and Microsoft 365. Older versions can open the file, but the transitions may not play.

Can I use it for client work?

Yes. You can use it for your own presentations and for client projects. Reselling or redistributing the template file is not allowed.

Can I change the colors and photos?

Yes. Everything is native PowerPoint: recolor shapes in a few clicks and right-click any photo, then choose Change Picture.
